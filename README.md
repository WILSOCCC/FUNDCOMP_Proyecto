## Proyecto Glosario de Conceptos

### Conceptos de la actividad 2:  

<p> </p>

- **1. Algortimo:** Es una serie de pasos para poder resolver un problema, ejemplo: necesito calcular el promedio de un alumno, leo las calificaciones, hago la fórmula para el promedio e imprimo el resultado.

- **2. Programa:** Es el conjunto de instrucciones en código que una máquina puede entender y por la tanto, ejecuta, ejemplo: inicio el programa de la calculadora, la máquina ejecuta las instrucciones del programa para poder iniciar y usar el programa.
- **3. Código fuente:** Es el código original escrito por el programador en el lenguaje de programación que se usó, ejemplo: el código original de una calculadora en JavaScript hecho por alguien.
- **4. Lenguaje de programación:** Conjunto definidos de palabras y semántica para hacer que un texto lo pueda entender una computadora, ejemplo: Python, C#, Java.
- **5. Sintaxis:** Son las reglas que tiene un lenguaje de programación como si fuera un idioma real, define donde irán elementos del lenguaje como corchetes, llaves y mayúsculas, ejemplo: el código generará un error de sintaxis si no se cierran bien las llaves.
- **6. Variable:** Es un espacio en la memoria del programa en el que se puede almacenar un tipo de dato para usarlo durante la ejecución del programa, ejemplo: una variable de tipo entero que se usa para llevar un conteo y se le incrementa el valora lo largo del programa.
- **7. Constante:** Al igual que la variable, es un espacio en el que se puede almacenar un tipo de dato, pero al definir su valor, este no puede cambiar durante el programa, ejemplo: se define una constante en donde se almacena una contraseña y su valor no debe cambiar durante la ejecución.
- **8. tipo de dato:** No todos los datos son iguales, los tipos de datos ayudan a definir si el valor de una variable será un texto, un carácter, un número entero, un número decimal, uno booleano, entre otros, ejemplo: un tipo de dato carácter sólo puede tener una letra y un string contiene una cadena de caracteres para formar un texto.
- **9. Operador:** Son símbolos que le dan una instrucción a una computadora para hacer cálculos, comparaciones o condiciones, ejemplo: comparar si un número es mayor que otro.
- **10. Expresión:** Es una combinación de variables, constantes valores, operadores y que al final devuelve un valor, ejemplo: sumar una variable con una constante.
- **11. Condicional:** Es una condición en una instrucción para decidir qué hará a continuación la máquina, ejemplo: si una variable es mayor a un número el programa hará algo, si no lo es, hará otra cosa.
- **12. Bucle:** Se utiliza para hacer un ciclo en un pedazo de código y evitar repetir instrucciones, ejemplo: se hace un bucle para imprimir la tabla de multiplicar de un número.
- **13. Función:** Es un pedazo de código que se puede reutilizar para no repetir código, la puedes llamar desde cualquier parte del programa para realizar sus instrucciones, ejemplo: una función de sumar, la llamas pasándole dos números para que los sume.
- **14. Parámetro:** Son las variables que una función utilizará en sus instrucciones, son los datos que reciben cuando son llamadas, ejemplo: una función que recibe un número para hacer operaciones con él.
- **15. Argumento:** Son los datos que se le pasarán a la función cuando es llamada, ejemplo: le pasas dos números a una función al llamarla para que haga algo con ellas.
- **16. Retorno:** Es lo que devuelve una función al realizar un conjunto de instrucciones, ejemplo: la función devuelve un total después de calcular los precios y las cantidades de productos que un cliente llevará.
- **17. Arreglo:** Un arreglo puede ser de un tipo de dato que almacena más de un valor del mismo tipo por posiciones, ejemplo: un arreglo que contiene varios nombres.
- **18. Objeto:** Es una forma de agrupar información en común, ejemplo: una persona que tiene edad y un nombre.
- **19. Método:** Es un pedazo de código de una clase para hacer una instrucción dentro de dicha clase y al igual que las funciones, se pueden llamar para realizar instrucciones, ejemplo: método de una clase de productos en el que al llamarlo se agregan sus atributos a una tabla.
- **20. Evento:** Se trata de una acción durante la ejecución de un programa y que el sistema necesita hacer algo como mostrar información, ejemplo: el evento click de un botón que muestra alguna información.

### Conceptos de la actividad 4:

<p></p>

- **1. Compilador:** Herramienta que traduce el código del lenguaje de programación escrito para traducirlo en código máquina para que la computadora lo pueda entender. Ejemplo: Varios lenguajes tienen sintaxis y reglas, pero estas no las entiende la máquina y deben ser traducidos para que sepa qué hacer.

- **2. Intérprete:** Es el programa o herramienta que procesa el código de un proyecto línea por línea, lo analiza y prepara la ejecución de forma consecutiva. Ejemplo: Python utiliza un intérprete para ejecutar el código línea por línea.
- **3. Depurador (Debugger):** Herramienta que permite examinar y corregir el código o su funcionamiento paso a paso cuando este se ejecuta. 
- **4. IDE:** Entorno de desarrollo que incluye varias herramientas para escribir código, depurador y compilador para facilitar el desarrollo del programa. Ejemplo: Visual Studio Code.
- **5. Editor de código:** Herramienta o programa para escribir, editar y gestionar código con un lenguaje de programación. Ejemplo: Notepad++.
- **6. Biblioteca (Library):** Código ya escrito previamente que se guarda en el programa para poder usarlo y reutilizarlo en todo el código. Ejemplo: Bibliotecas matemáticas para hacer raíces y potencias sin escribir mucho código.
- **7. Framework:** Conjunto de herramientas y reglas que ayudan a simplificar el desarrollo de software. Ejemplo: .NET Framework.
- **8. API:** Interfaz de Programación de Aplicaciones, permite que dos o más partes diferentes del programa puedan intercambiar información o realizar instrucciones sin conocer el código o el funcionamiento entre ellos. Ejemplo: API de PayPal para pagar.
- **9. Repositorio:** Es el espacio en donde se almacena tanto el código y el historial de sus cambios o actualizaciones.
- **10. Control de versiones:** Es el proceso de mantener un historial de cambios en el código.
- **11. Git:** Sistema de control de versiones que permite a los desarrolladores rastrear y colaborar los cambios que se hayan hecho en el código.
- **12. Github:** Es la plataforma con el que se puede trabajar con Git, permite crear repositorios en un almacenamiento en la nube para que varios desarrolladores puedan trabajar en un solo proyecto.
- **13. Rama (Branch):** La rama está dentro de un repositorio y permite trabajar en correcciones de manera aislada del código principal.
- **14. Commit:** Es un punto de guardado del programa o archivo, permite establecer un punto en el desarrollo del programa para volver a ese punto si se necesita. Ejemplo: se hicieron cambios en el código pero puede que falle así que se establece este punto de guardado para volver al código anterior.
- **15. Merge:** El proceso de combinar cambios de una rama en otra.
- **16. Callback:** Función que se pasa como argumento a otra función para que esta última la ejecute en un momento determinado, ya sea inmediatamente, después de un evento o tras completar una tarea.
- **17. Programación síncrona:** Permite al programa ejecutar una tarea a la vez y no permite la ejecución de otras hasta que la que se está ejecutando termine, por lo que es secuencial.
- **18. Programación asíncrona:** Permite al programa ejecutar varias tareas a la vez sin esperar a que cada tarea termine para empezar otra.
- **19. JavaScript:** Un lenguaje de programación esencial para el desarrollo web que permite agregar interactividad a las páginas, como animaciones y validación de formularios.
- **20. TypesScript:** Una extensión de JavaScript que añade tipado estático, lo que mejora la escalabilidad y mantenibilidad de proyectos grandes.
